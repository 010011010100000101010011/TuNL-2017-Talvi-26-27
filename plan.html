Reading the plan

Menus rotate, phases hold

Within a phase the menus repeat with harder doses (the "+" weeks). Menus only change at phase boundaries or when a whole squad clears the progression gate early — then move that player/group to the next menu's exercises.

Individual progression inside the group

Sessions are planned for the group, but the gate is per player. An assistant runs the physical station, so players can each be on their own step of the ladder while doing the same circuit.

Ball station stays free

Every ball block names a placeholder game; when winter themes are set (first touch, pressing, passing, dribbling…), replace the placeholder — durations and group logic don't change.

Video-record test weeks

W6 / 12 / 18 / 24: film the same reference drills (plank family, split squat, pistol on box, broad jump). Compare side-by-side at season end in W24.
